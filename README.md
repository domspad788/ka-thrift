# K&A This & That Thrift — Website

A premium, single-page marketing website for **K&A This & That Thrift**, a family-owned
thrift & antique store in Albany, NY. Antique treasure-map / vintage mercantile aesthetic
with modern, conversion-focused UX. The real store photography is the hero; the theme frames it.

---

## What this project is

A **fully self-contained static website**. There is **no build step, no framework, and no
runtime dependencies**. Everything ships in a single `index.html` with embedded CSS and
vanilla JavaScript. This makes it maximally portable: any developer can open, edit, and deploy it.

> Note: This project was hand-built as a static site (not generated by Reflow or any
> SPA framework), so there are no framework/router/component files or a node dependency tree.
> The `package.json` included here only provides optional convenience scripts for serving
> the site locally — the site itself needs none of it to run.

## Project structure

```
ka-thrift/
├── index.html          # The entire site: HTML + embedded CSS (<style>) + vanilla JS (IIFE)
├── img/                # Optimized, web-ready images (served by the site)
│   ├── IMG_XXXX.jpg        #   full size (max 1600px)
│   ├── IMG_XXXX-sm.jpg     #   thumbnail/card size (max 900px)
│   └── IMG_098X-hero.jpg   #   hero backgrounds (max 2000px)
├── images/             # Original full-resolution source photos (not served; kept for re-export)
├── optimize.py         # Image pipeline: regenerates img/ from images/ using Pillow
├── package.json        # Optional convenience scripts (local serving only)
├── .claude/launch.json # Local preview config (python http.server on port 5180)
└── README.md           # This file
```

### Pages / routes
This is a **single-page site**. All content lives on one route (`/` → `index.html`).
In-page navigation uses anchor links to these section IDs:
`#top` (hero) · `#treasures` · `#fresh` (Fresh Off The Hunt) · `#about` · `#gallery` ·
`#why` · `#reviews` · `#visit` · `#follow`.

## Run it locally

You only need a static file server. Pick whichever you have:

**Python (no install required):**
```bash
cd ka-thrift
python -m http.server 5180
# open http://localhost:5180
```

**Node (via the included package.json):**
```bash
cd ka-thrift
npm run start          # uses npx serve on port 5180
# open http://localhost:5180
```

**Or just open the file:** double-click `index.html`. (A server is recommended so that
relative image paths and the Google Maps embed behave exactly as in production.)

## Deploy

Because it is fully static, deploy the folder to any static host. No build command is needed.

- **Netlify / Cloudflare Pages / GitHub Pages:** drag-and-drop or point to this folder.
  Build command: *(none)*. Publish directory: the project root (where `index.html` lives).
- **Vercel:** "Other" framework preset, no build command, output directory = project root.
- **Any web server (Apache/Nginx/S3):** upload `index.html` and the `img/` folder. Keep
  their relative paths intact (the HTML references `img/...`).

The only files required in production are `index.html` and the `img/` directory.
`images/`, `optimize.py`, `.claude/`, `package.json`, and this README are dev-only.

## Regenerating images

If you add or replace source photos in `images/`, regenerate the optimized `img/` set:

```bash
pip install Pillow
python optimize.py
```

This writes, for each source photo: a full version (`name.jpg`, ≤1600px, q82), a card/thumb
version (`name-sm.jpg`, ≤900px, q78), and hero crops for `IMG_0989`/`IMG_0988`
(`name-hero.jpg`, ≤2000px, q85). All progressive JPEG, EXIF-orientation honored.

## Tech notes / features

- **Fonts (Google Fonts, loaded in `<head>`):** Rye (western display), IM Fell English /
  IM Fell English SC (vintage serif), EB Garamond (body serif).
- **Color system:** CSS custom properties in `:root` (aged parchment, espresso, burnt gold,
  copper, wax red, etc.).
- **Interactions (vanilla JS, no libraries):** scroll-reveal (IntersectionObserver),
  sticky header, mobile nav, lightbox gallery (keyboard nav), hero parallax, animated gold
  "dust" canvas (pauses off-screen/when tab hidden), once-per-session intro seal,
  expedition-trail scroll-spy, compass watermark, "Fresh Off The Hunt" auto-scroll marquee
  (pauses on hover, off-screen, and under reduced-motion), and a hidden-gem easter egg.
- **Accessibility:** full `prefers-reduced-motion` support (intro auto-skips, animations
  disabled, marquee becomes a manual scroll strip), semantic landmarks, ARIA labels,
  keyboard-operable controls.
- **Performance:** optimized progressive JPEGs, `loading="lazy"` on below-the-fold images,
  off-screen animation pausing.
- **SEO:** descriptive title/meta, semantic headings, image alt text.
